## Projeto desenvolvido em Python para análise de temperaturas de máquinas industriais.
DigiTech Firjan SENAI - 

Sistema de Monitoramento de Temperatura
Funcionalidades
- Leitura de temperaturas e limite de segurança
- Cálculo de média, máxima e mínima
- Análise de tendência (Subindo / Descendo / Estável)
- Detecção de anomalias (valores fora do padrão)
- Visualização gráfica com Seaborn e Matplotlib
- Gráfico salva como `grafico.png` e mostra tendência no título

## Tecnologias
Python 3.x
Pandas
NumPy
Matplotlib
Seaborn
